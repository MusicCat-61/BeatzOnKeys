## English

1.3.0.5 makes the downloaded tracks look and behave like the local playlist, fixes a retry bug and merges two buttons into one.

### One button that knows what you pasted

- **Words in the field → «Найти». A link → «Скачать».** The button swaps itself, so there is no more choosing between two actions every time. An empty field leaves it disabled.

### Listening comes before saving

- **Every search result has a listen button.** It fetches the audio, plays it at once and shows the download progress right in the row — you hear what you are about to keep instead of guessing from a title.
- **Listening does not save anything.** The track lands in «Скачанные» only when you press «Скачать» afterwards, which then reuses the file already in the cache instead of downloading it twice.

### The downloaded tab is a playlist now

- **Same look as the local list:** title, status line, a state chip («Готово» / «43%» / «Ошибка»), up and down arrows with disabled edges, delete, and drag-and-drop with the accent insertion line.
- **A counter next to the heading**, exactly like «Треки 14» on the local page.
- **Failures explain themselves in the row** — «YouTube ограничил доступ» instead of a popup.

### Bug: the second download of the same video showed the first error

- **A retry starts clean.** The row is reset before every attempt, so a stale `ErrorMessage` and an old progress value cannot survive into the new try. That was the whole bug: the row kept the first failure and displayed it while the second download was already running.
- **A file already in the cache is reused**, not fetched again — asking twice for the same video is now harmless.

### Transport

- **No per-row play buttons anywhere.** A row is selected by clicking it, exactly like the local playlist; there is one way to choose a track instead of two.
- **No prev/next arrows either.** They were tried and removed: they only saved one mouse click, duplicated the existing selection, and behaved differently on the two tabs (selecting on one, starting playback on the other). Auto-advance and looping already live in «Поведение».
- **«Старт» plays the active tab.** On «Локально» it starts the local list, on «YouTube» it starts the cached tracks.

## Русский

1.3.0.5 приводит скачанные треки к виду локального плейлиста, чинит баг с повтором и объединяет две кнопки в одну.

### Одна кнопка, которая понимает, что вставили

- **Слова в поле → «Найти». Ссылка → «Скачать».** Кнопка меняется сама, так что выбирать между двумя действиями больше не нужно. Пустое поле — кнопка неактивна.

### Сначала слушаем, потом сохраняем

- **У каждого результата поиска есть кнопка прослушивания.** Она забирает звук, сразу включает его и показывает прогресс прямо в строке — вы слышите, что собираетесь оставить, а не гадаете по названию.
- **Прослушивание ничего не сохраняет.** Трек попадает в «Скачанные» только после нажатия «Скачать», и тогда уже скачанный файл берётся из кеша, а не качается второй раз.

### Вкладка скачанного теперь плейлист

- **Тот же вид, что у локального списка:** название, строка статуса, чип состояния («Готово» / «43%» / «Ошибка»), стрелки вверх-вниз с отключением на краях, удаление и перетаскивание с акцентной линией вставки.
- **Счётчик рядом с заголовком**, ровно как «Треки 14» на локальной странице.
- **Ошибка объясняется в самой строке** — «YouTube ограничил доступ» вместо всплывающего окна.

### Баг: при повторном скачивании того же видео светила первая ошибка

- **Повтор начинается с чистого листа.** Строка сбрасывается перед каждой попыткой, поэтому старый `ErrorMessage` и прежний прогресс не переживают новую попытку. В этом и был весь баг: строка хранила первую ошибку и показывала её, пока второе скачивание уже шло.
- **Файл, который уже в кеше, переиспользуется**, а не качается заново — попросить одно и то же видео дважды теперь безопасно.

### Управление

- **Кнопок ▶ в строках нет нигде.** Строка выбирается кликом, ровно как в локальном плейлисте; способ выбрать трек один, а не два.
- **Стрелок пред./след. тоже нет.** Их попробовали и убрали: они экономили один клик мышью, дублировали существующий выбор и вели себя по-разному на двух вкладках (на одной выбирали, на другой запускали). Автопереход и зацикливание и так живут в «Поведении».
- **«Старт» играет активную вкладку.** На «Локально» запускает локальный список, на «YouTube» — скачанные треки.
