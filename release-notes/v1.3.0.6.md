## English

1.3.0.6 reworks the search tab, makes the yt-dlp card state-driven and moves the update notice into the window.

### Listening before saving

- **Search results are cached automatically.** As soon as the list appears, every row is fetched into the cache one by one, so pressing play works immediately instead of waiting on the network.
- **The play button moved to the left of the title** and stopped overlapping the Download button — the earlier layout squeezed two buttons into the same column.
- **Listening is offered only when the file is really on disk.** Until then the button stays disabled and the row says «Кешируется…» with its progress; a row that could not be fetched says «Не удалось подготовить» instead of pretending to be playable.

### Bug: the downloaded list sometimes showed an id instead of the title

- **A cache hit no longer invents a title.** When the file was already cached, the service returned the file name as the title — and the file is named after the video id, so `dQw4w9WgXcQ` ended up in the list. It now reports no title at all, and the row keeps the name it already had.

### The yt-dlp card follows its state

- **The state is the headline**, and the path is gone from it: «yt-dlp 2025.01.15» when installed, «yt-dlp не установлен» when missing, «yt-dlp повреждён — нужен ремонт» when a file sits in the bin folder but is not a usable executable.
- **One button whose label matches the situation:** «Скачать yt-dlp» when there is nothing, «Починить yt-dlp» for a damaged file, «Обновить yt-dlp» only when a newer release actually exists upstream.
- **No button at all when the binary is current.** The card asks GitHub for the newest yt-dlp release, compares dates numerically, and stays quiet when there is nothing to do.
- **Repair and update replace the file**, while a plain download only fills a gap — the old code returned the existing file even when the point was to overwrite it.

### Update notices moved into the window

- **No more tray balloon.** The notice is a dialog drawn with the app's own theme, and it carries the release notes in a scrollable block.
- **«Открыть «О программе»» takes you straight to the download**, «Позже» leaves you alone; the same version is not announced twice.

## Русский

1.3.0.6 переделывает вкладку поиска, делает карточку yt-dlp зависимой от состояния и переносит уведомление об обновлении в окно.

### Сначала слушаем, потом сохраняем

- **Результаты поиска кешируются автоматически.** Как только список появился, каждая строка по очереди забирается в кеш, поэтому кнопка прослушивания работает сразу, а не ждёт сеть.
- **Кнопка прослушивания переехала влево от названия** и больше не наезжает на «Скачать» — прежняя разметка запихивала две кнопки в одну колонку.
- **Слушать можно только когда файл реально на диске.** До этого кнопка неактивна, а строка показывает «Кешируется…» с прогрессом; если забрать не удалось — «Не удалось подготовить» вместо ложной доступности.

### Баг: в списке скачанного иногда появлялся id вместо названия

- **Попадание в кеш больше не выдумывает название.** Когда файл уже был в кеше, сервис возвращал имя файла как заголовок — а файл назван по id видео, поэтому в списке оказывался `dQw4w9WgXcQ`. Теперь он не сообщает заголовок вовсе, и строка сохраняет то имя, которое уже знала.

### Карточка yt-dlp живёт по состоянию

- **Состояние — это заголовок**, путь из него убран: «yt-dlp 2025.01.15» когда установлен, «yt-dlp не установлен» когда нет, «yt-dlp повреждён — нужен ремонт» когда файл лежит в папке, но не запускается.
- **Одна кнопка, чья надпись соответствует ситуации:** «Скачать yt-dlp» когда пусто, «Починить yt-dlp» для повреждённого файла, «Обновить yt-dlp» только когда в апстриме действительно есть новее.
- **Кнопки нет вовсе, когда версия актуальна.** Карточка спрашивает у GitHub последний релиз yt-dlp, сравнивает даты численно и молчит, если делать нечего.
- **Ремонт и обновление заменяют файл**, а обычное скачивание лишь закрывает пробел — старый код возвращал существующий файл даже когда его нужно было перезаписать.

### Уведомления об обновлении переехали в окно

- **Шарика в трее больше нет.** Уведомление — это диалог в собственной теме приложения, и в нём есть прокручиваемый блок с релиз-нотами.
- **«Открыть «О программе»» ведёт прямо к скачиванию**, «Позже» оставляет в покое; про одну и ту же версию не сообщается дважды.
