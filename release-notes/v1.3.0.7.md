## English

1.3.0.7 fixes the stuck cache progress, splits the two caches, and makes a click on a row play it.

### The search cache no longer sits at 0%

- **The progress was never printed at all.** The download passed `--print`, and yt-dlp documents that `--print` implies `--quiet` — which silences the progress bar, so the template that feeds the percentage never fired. `--progress` is now passed explicitly, and a regression test pins the flags.
- **The metadata phase reports something too.** Resolving a video takes seconds on its own; the row used to look frozen at 0% for that whole time. It now reports a small non-zero value so work is visibly under way.
- **A file that cannot be decoded no longer breaks the download.** `TryLoad` promises to answer "can this be opened?" instead of throwing, but a corrupt M4A made Media Foundation throw its own exception type, which escaped and skipped the WAV fallback. Every failure is now caught and turned into "no".

### Two caches, two clear buttons

- **«Очистить кеш поиска» lives on the Search tab** and shows the space taken by previews only — files that no downloaded row points at. Kept tracks are untouched.
- **«Очистить скачанные» lives on the Downloaded tab** and removes the tracks and their files.
- **The shared card no longer has a clear button** and only reports the total, because a single button could never mean both things.
- **The occupied space updates as the list fills**, not only at the end, and it is recomputed after any removal.

### Rows and buttons

- **Clicking a row in Downloaded plays it**, exactly like the local playlist; buttons inside the row (arrows, bin) still handle their own clicks and do not trigger playback.
- **The listen button in Search got a round backing**, accented when the file is cached and outlined when it is not, so it reads as a player button instead of a stray glyph.
- **Removing a track also forgets it in the search list**, so a row can never claim to play a file that was just deleted.

### About window

- **The description was rewritten to match the app**: local files and YouTube, typing drives the volume, Start plays the active tab, the idle pause silences and restores, and the YouTube section searches, previews and caches through yt-dlp.

## Русский

1.3.0.7 чинит зависший прогресс кеша, разделяет два кеша и включает трек по клику на строку.

### Кеш поиска больше не висит на 0%

- **Прогресс вообще не печатался.** При скачивании передавался `--print`, а в документации yt-dlp прямо сказано, что `--print` подразумевает `--quiet` — а тот глушит полосу прогресса, поэтому шаблон, из которого берутся проценты, никогда не срабатывал. Теперь `--progress` передаётся явно, и регрессионный тест закрепляет флаги.
- **Фаза получения метаданных тоже что-то сообщает.** Разбор видео сам по себе занимает секунды; всё это время строка выглядела замороженной на 0%. Теперь она сообщает небольшое ненулевое значение, и видно, что работа идёт.
- **Нечитаемый файл больше не ломает скачивание.** `TryLoad` обещает отвечать «откроется ли это?» вместо исключения, но битый M4A заставлял Media Foundation бросить собственный тип исключения, который вылетал наружу и пропускал фолбэк в WAV. Теперь любая ошибка превращается в «нет».

### Два кеша — две кнопки очистки

- **«Очистить кеш поиска» живёт на вкладке «Поиск»** и показывает место, занятое только предпросмотрами — файлами, на которые не ссылается ни одна скачанная строка. Скачанные треки не трогаются.
- **«Очистить скачанные» живёт на вкладке «Скачанные треки»** и удаляет треки вместе с их файлами.
- **В общей карточке кнопки очистки больше нет**, она показывает только общий размер: одна кнопка не могла бы означать оба действия.
- **Занятое место обновляется по мере заполнения списка**, а не только в конце, и пересчитывается после любого удаления.

### Строки и кнопки

- **Клик по строке в «Скачанных» включает трек**, ровно как в локальном плейлисте; кнопки внутри строки (стрелки, корзина) обрабатывают свои клики сами и воспроизведение не запускают.
- **Кнопка прослушивания в поиске получила круглую подложку**: акцентную, когда файл в кеше, и обведённую, когда ещё нет, — теперь она читается как кнопка плеера, а не случайный значок.
- **Удаление трека забывает его и в списке поиска**, чтобы строка не обещала включить только что удалённый файл.

### Окно «О программе»

- **Описание переписано по факту**: локальные файлы и YouTube, набор управляет громкостью, «Старт» играет активную вкладку, пауза при простое глушит и возвращает звук, а раздел YouTube ищет, слушает и кеширует через yt-dlp.
