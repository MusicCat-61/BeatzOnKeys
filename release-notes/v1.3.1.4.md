## English

1.3.1.4 brings the track name back to the player card and stops the update dialog from covering the About window.

### The player card names the track again

- **The heading claimed the whole card.** The source line and the track name were written into the same field, so the card read "Now playing · local" and the file name was gone. The heading now carries the source and the line below it carries the track.
- **A test now watches this**: the captured window must render both the source and the track name, and they must differ.

### The update notice steps aside

- **If the About window is already open, the notice does not appear.** That window shows the update state and the download button itself, so a dialog on top of it only repeated the message and blocked what the user opened it for.
- **It counts as announced**, so it will not pop up the moment the About window is closed either.

## Русский

1.3.1.4 возвращает название трека в карточку плеера и не даёт уведомлению об обновлении перекрывать «О программе».

### Карточка плеера снова называет трек

- **Заголовок занял всю карточку.** Источник и название писались в одно и то же поле, поэтому карточка читалась как «Сейчас играет · локально», а имени файла не было вовсе. Теперь источник — в заголовке, а название — строкой ниже.
- **Теперь за этим следит тест**: на снятом окне должны отрисоваться и источник, и название, и они должны различаться.

### Уведомление об обновлении уступает место

- **Если окно «О программе» уже открыто, уведомление не появляется.** Там и так видно состояние обновления и кнопку загрузки, а диалог поверх лишь повторял сообщение и перекрывал то, ради чего окно открыли.
- **Считается, что пользователь уже уведомлён**, поэтому уведомление не выскочит и сразу после закрытия окна.
