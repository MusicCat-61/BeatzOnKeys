## English

1.3.1.5 puts every piece of data under one root that follows where the executable sits.

### One root, three modes

- **Portable**: the exe sits in an ordinary writable folder, so settings, logs, updates, the YouTube cache, the yt-dlp binaries and download scratch space all live beside it.
- **ChosenDirectory**: the exe sits on the desktop or in a place that must not hold data — the profile root, `%PUBLIC%`, `C:\`, `C:\Windows`, Program Files, `%TEMP%`. The program asks for a folder once and creates `BeatzOnKeys\` inside it.
- **LocalAppData**: the fallback, `%LOCALAPPDATA%\BeatzOnKeys\`. Cancelling the question is a valid answer: the run continues there and the question returns next time.
- **The desktop is detected through the shell** rather than the environment variable, because a redirected desktop is exactly the case where guessing wrong would scatter files.

### What the folder picker does

- **The choice is written to `%LOCALAPPDATA%\BeatzOnKeys\storage.json`** through a temporary file, so an interrupted save leaves either the old answer or the new one.
- **A folder that disappeared asks again** and the recorded answer stays on disk — a missing drive is not a reason to forget what the user chose.
- **A malformed `storage.json` is not a crash**: it means "no choice yet".

### Migrating older data

- **On the first start in Portable or ChosenDirectory mode**, the old `%LOCALAPPDATA%\BeatzOnKeys\` data is copied into the new root: settings, logs, updates, the music cache, the binaries and scratch space.
- **The originals stay where they are**, and the copy never runs twice — a user who tries the portable build and goes back loses nothing.

### The cache folder picker is gone

- **The YouTube cache always lives in `<Root>\Music`.** A separate "change cache folder" button only made sense while the cache could be anywhere; with one root it would be a second, conflicting answer.
- **Absolute `CachedPath` values keep working**, so tracks cached in an old folder stay playable as long as the file exists.

### Telegram

- **The About window now has two Telegram buttons, labelled so they cannot be confused**: «Канал программы» (`t.me/beatzonkeys`) for news and releases, and «Автор» (`@music_cat1`) for the author. Both are mentioned in the guide and both READMEs.

## Русский

1.3.1.5 собирает все данные в один корень, который зависит от того, откуда запущена программа.

### Один корень, три режима

- **Portable**: exe лежит в обычной папке на запись, поэтому настройки, логи, обновления, кеш YouTube, бинарники yt-dlp и временные файлы загрузки живут рядом с ним.
- **ChosenDirectory**: exe лежит на рабочем столе или там, где данных быть не должно — корень профиля, `%PUBLIC%`, `C:\`, `C:\Windows`, Program Files, `%TEMP%`. Программа один раз спрашивает папку и создаёт в ней `BeatzOnKeys\`.
- **LocalAppData**: запасной вариант, `%LOCALAPPDATA%\BeatzOnKeys\`. Отмена — допустимый ответ: запуск продолжается там, а вопрос вернётся в следующий раз.
- **Рабочий стол определяется через оболочку**, а не через переменную среды: перенаправленный рабочий стол — ровно тот случай, когда догадка разложила бы файлы не туда.

### Что делает выбор папки

- **Выбор записывается в `%LOCALAPPDATA%\BeatzOnKeys\storage.json`** через временный файл, поэтому прерванная запись оставляет либо старый ответ, либо новый.
- **Пропавшая папка заставляет спросить снова**, а запись о выборе остаётся на диске: исчезнувший диск — не повод забыть, что выбрал пользователь.
- **Битый `storage.json` — не падение**: он означает «выбора ещё нет».

### Миграция старых данных

- **При первом запуске в режиме Portable или ChosenDirectory** старые данные из `%LOCALAPPDATA%\BeatzOnKeys\` копируются в новый корень: настройки, логи, обновления, кеш музыки, бинарники и временные файлы.
- **Оригиналы остаются на месте**, и копирование не выполняется повторно — пользователь, попробовавший портативную сборку и вернувшийся назад, ничего не теряет.

### Выбора папки кеша больше нет

- **Кеш YouTube всегда лежит в `<Root>\Music`.** Отдельная кнопка «изменить папку кеша» имела смысл, пока кеш мог быть где угодно; при одном корне это был бы второй, конфликтующий ответ.
- **Абсолютные `CachedPath` продолжают работать**, поэтому треки, закешированные в старой папке, остаются доступными, пока файл существует.

### Telegram

- **В окне «О программе» теперь две кнопки Telegram с различимыми подписями**: «Канал программы» (`t.me/beatzonkeys`) для новостей и релизов и «Автор» (`@music_cat1`) для связи с автором. Оба упомянуты в гайде и в обоих README.
