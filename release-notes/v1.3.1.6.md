## English

1.3.1.6 asks where the data should live in the app's own dialog, after the window is up.

### The question now has context

- **It was a bare system folder picker, shown before anything was drawn.** Worse, its title read `Storage_PickFolder`: the dialog was created before the language dictionaries were loaded, so the label never resolved. A first launch looked like a bug.
- **The program now starts normally and then asks**, in the same themed dialog as everything else, with a title, an explanation of why the folder is needed, and two named buttons: «Выбрать папку…» and «Не сейчас».
- **Cancelling is handled at both steps.** Closing the question keeps the data in the per-user folder and the question returns next time. Closing the folder picker does the same, without a second message — the user just said "not now".

### Choosing a folder

- **The picked folder gets a `BeatzOnKeys` subfolder** and older data is copied into it right away.
- **The running session keeps its current paths** and the new location takes effect after a restart, which the confirmation says plainly instead of pretending the move already happened.

## Русский

1.3.1.6 спрашивает, где хранить данные, в собственном диалоге программы — после того, как окно появилось.

### У вопроса появился контекст

- **Это был голый системный выбор папки, показанный до того, как что-либо отрисовалось.** Хуже того, в заголовке стояло `Storage_PickFolder`: диалог создавался раньше, чем загрузились словари локализации, поэтому подпись не находилась. Первый запуск выглядел как баг.
- **Теперь программа сначала нормально запускается и лишь потом спрашивает** — в том же тематическом диалоге, что и всё остальное: с заголовком, объяснением, зачем нужна папка, и двумя понятными кнопками: «Выбрать папку…» и «Не сейчас».
- **Отмена обрабатывается на обоих шагах.** Закрыли вопрос — данные остаются в папке пользователя, а вопрос вернётся в следующий раз. Закрыли выбор папки — то же самое, без второго сообщения: пользователь только что сказал «не сейчас».

### Выбор папки

- **В выбранной папке создаётся подпапка `BeatzOnKeys`**, и старые данные сразу копируются туда.
- **Текущий сеанс продолжает работать по прежним путям**, а новый адрес вступает в силу после перезапуска — так и написано в подтверждении, без вранья о том, что перенос уже случился.
