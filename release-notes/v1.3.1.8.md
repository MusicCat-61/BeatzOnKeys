## English

1.3.1.8 restarts the program after you pick a folder, and the cache hint now shows the real path.

### The last dialog restarts

- **Its only button is «Перезапустить».** A running session cannot switch its data root underneath itself — the settings, the log file and the cache are all open — so the honest choice is to start again, not to say "done" and quietly do nothing.
- **The text says so plainly**: the data will live in the new folder, and the program has to restart to use it, which happens as soon as you press the button.
- **The restart is handled carefully**: the single-instance lock is released first, and the new copy waits two seconds in a hidden shell, because otherwise it would find the old one still running, signal it and quit.

### The cache hint tells the truth

- **It used to print a hardcoded `%LOCALAPPDATA%\BeatzOnKeys\Music`.** With a root that follows the executable, that line became a lie the moment the data moved. It now reads the folder the app is actually using, so a portable copy shows its own path and a chosen folder shows that one.

## Русский

1.3.1.8 перезапускает программу после выбора папки, а подсказка о кеше показывает реальный путь.

### Последний диалог перезапускает

- **Единственная кнопка в нём — «Перезапустить».** Работающий сеанс не может подменить свой корень данных на ходу: настройки, файл лога и кеш уже открыты. Честный выбор — начать заново, а не сказать «готово» и молча ничего не сделать.
- **Текст говорит это прямо**: данные будут храниться в новой папке, и для перехода программу нужно перезапустить, что произойдёт сразу после нажатия кнопки.
- **Перезапуск сделан аккуратно**: сначала освобождается замок единственного экземпляра, а новая копия ждёт две секунды в скрытой оболочке — иначе она нашла бы старую ещё работающей, подала бы ей сигнал и завершилась сама.

### Подсказка о кеше больше не врёт

- **Раньше там был жёстко прописан `%LOCALAPPDATA%\BeatzOnKeys\Music`.** С корнем, который следует за исполняемым файлом, эта строка становилась ложью, как только данные переезжали. Теперь показывается папка, которую программа действительно использует: портативная копия показывает свой путь, а выбранная папка — свой.
