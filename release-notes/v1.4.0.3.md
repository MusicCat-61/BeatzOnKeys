## English

1.4.0.3 makes the TikTok list behave like the playlist, names every row by what the video is called, and drops the per-row play button that asked the same question twice.

### The row is managed the way the playlist is

- **The play button is gone from each row.** Clicking a row already starts it, so a second button inside the same row only offered the same action twice.
- **The controls on the right are now the playlist's own**: the track length with its clock, the format chip, the two arrows that reorder, and the bin that removes. The arrows disable themselves at the ends of the list, exactly as they do there.
- **The folder line was left out on purpose.** Every TikTok row lives in `Music\TikTok`, so printing the path on each of them would repeat the same sentence down the whole page; the cache card above already names the folder once.

### A row is named by the video, not by its id

- **`7704233321361870094` is no longer the name.** The title TikTok itself reports is what the row shows, falling back to the id only when even that cannot be read.
- **The title is fetched in the same yt-dlp call as the file path**, on one line with a separator, so the parse needs no second process and a title containing spaces, pipes or colons survives intact.
- **The format chip reads the real extension**, so an mp3 row says MP3 and a converted one says WAV, instead of assuming a single format for the whole list.

## Русский

1.4.0.3 заставляет список TikTok вести себя как плейлист, называет строку тем, как называется ролик, и убирает кнопку прослушивания, которая спрашивала одно и то же дважды.

### Строка управляется как в плейлисте

- **Кнопки прослушивания в строке больше нет.** Нажатие на строку и так запускает трек, так что вторая кнопка внутри той же строки предлагала то же самое второй раз.
- **Справа теперь управление из плейлиста**: длительность с часиками, чип формата, две стрелки для перемещения и корзина для удаления. Стрелки сами гаснут на краях списка — ровно как там.
- **Строка с путём убрана намеренно.** Каждая строка TikTok лежит в `Music\TikTok`, поэтому путь на каждой из них повторял бы одно и то же предложение по всей странице; карточка кеша выше и так называет папку один раз.

### Строка называется по ролику, а не по id

- **`7704233321361870094` больше не название.** Строка показывает то имя, которое отдаёт сам TikTok, а id остаётся запасным вариантом на случай, когда не читается даже оно.
- **Название приходит тем же вызовом yt-dlp, что и путь**, одной строкой с разделителем: разбору не нужен второй процесс, а название с пробелами, чёрточками и двоеточиями остаётся целым.
- **Чип формата берёт настоящее расширение**, поэтому строка mp3 говорит MP3, а сконвертированная — WAV, вместо предположения об одном формате на весь список.
