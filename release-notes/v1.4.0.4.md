## English

1.4.0.4 stops blaming the provider for something TikTok decides itself, makes a click on any row start it, and keeps the TikTok cache heading from going blank.

### The wrong diagnosis is gone

- **"Your provider is blocking TikTok" was not true, and it is no longer said.** The message "Your IP address is blocked from accessing this post" is a translation of TikTok's own status `10204`, which the program now reads out of the page instead of taking from another tool's wording. It means TikTok will not serve that clip to this connection — a decision made by TikTok, with no provider involved.
- **Two different failures finally have two different sentences.** A regional refusal tells you another network may open the clip. A connection that broke halfway tells you to try again in a minute. Before, both said "the network will not reach TikTok".
- **The plate no longer offers a workaround that would not help.** Bypassing a provider's interference does nothing when TikTok itself declines the request, so the recommendation was removed rather than left as false hope. The plate now only describes the symptom, and still closes with the cross.
- **Private posts and private accounts are told apart** from both, using the same page code.

### A click starts the track

- **Rows in the TikTok list and in the local playlist now play on click**, exactly as a row in the YouTube list already did. That is why the per-row play button was unnecessary.
- **Clicking a row while the transport is already running switches the track** instead of restarting the session, and a row whose file is gone is never started.
- **Buttons inside a row keep their own click**, so the arrows and the bin do not also start playback.

### The cache heading cannot vanish

- **"TikTok cache" is never blank any more.** Before the first measurement — or after a refresh that could not run — the heading rendered as an empty line, which read as the row disappearing.
- **A measurement that fails now falls back to the zero label** and writes the reason to the log, instead of silently leaving the card without its name.

### A small wording fix

- **"Program channel" is now "Telegram channel"** in the about window, in both languages.

## Русский

1.4.0.4 перестаёт винить провайдера в том, что решает сам TikTok, включает трек по клику на любую строку и не даёт заголовку кеша TikTok пропадать.

### Неверный диагноз убран

- **«Провайдер не пускает к TikTok» было неправдой, и больше этого нет.** Сообщение «Your IP address is blocked from accessing this post» — это перевод собственного кода TikTok `10204`. Теперь программа читает код из самой страницы, а не берёт формулировку другого инструмента. Код означает, что TikTok не отдаёт этот ролик данному подключению — решение TikTok, провайдер тут ни при чём.
- **У двух разных отказов наконец две разные фразы.** Региональный отказ говорит, что с другой сети ролик может открыться. Оборвавшееся на середине соединение просит повторить через минуту. Раньше оба звучали как «сеть не пускает к TikTok».
- **Из плашки убран совет, который не помог бы.** Обход вмешательства провайдера бесполезен, когда отказывает сам TikTok, поэтому рекомендация удалена, а не оставлена ложной надеждой. Плашка теперь только описывает симптом и по-прежнему закрывается крестиком.
- **Закрытые ролики и закрытые аккаунты отличаются** от обоих случаев — по тому же коду страницы.

### Клик включает трек

- **Строки в списке TikTok и в локальном плейлисте включаются по клику** — ровно как строка в списке YouTube. Поэтому кнопка прослушивания в строке и была лишней.
- **Клик по строке во время воспроизведения переключает трек**, а не перезапускает сессию, а строка, у которой файла нет, не запускается вовсе.
- **Кнопки внутри строки обрабатывают свой клик сами**, поэтому стрелки и корзина не запускают воспроизведение заодно.

### Заголовок кеша не может исчезнуть

- **«Кеш TikTok» больше никогда не пустой.** До первого замера — или после обновления, которое не смогло выполниться, — заголовок рисовался пустой строкой, и это читалось как исчезнувшая строка.
- **Неудачный замер теперь откатывается к нулевому значению** и пишет причину в журнал, вместо того чтобы молча оставить карточку без названия.

### Маленькая правка текста

- **«Канал программы» стало «Телеграм канал»** в окне «О программе», на обоих языках.
