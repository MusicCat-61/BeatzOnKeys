## English

1.4.0 adds a TikTok section: paste a link, get the audio. It also gives every downloaded track its own file, and turns the little play button in the search results into a real pause.

### TikTok

- **A third tab, TikTok.** One field, one button. Paste a link to a clip, press Download, and the audio track lands in `Music\TikTok`.
- **Short links work too.** A `vm.tiktok.com/…` or `vt.tiktok.com/…` share link is followed first to learn the real address of the clip; only then is the audio fetched. Pasting the same link twice does not add a second copy.
- **Cancel is there while it runs.** The button appears only when there is something to stop, and it stops that download without touching the rest of the list.
- **The TikTok cache is its own.** Files sit apart from the YouTube cache, the counter counts only them, and Clear TikTok cache removes only them. The list is a separate collection from the Local playlist — counters and clearing are never shared.
- **No ffmpeg on this path.** When TikTok serves a video container instead of a separate audio track, the audio is unwrapped with the Media Foundation decoder the program already uses for the YouTube cache and written as WAV. One less thing to install.
- **Metadata comes from the page first.** The signed API is tried, then the public page, then the oembed endpoint for a title. `yt-dlp` stays as the very last resort — the build the YouTube section already uses, if it happens to be installed — because TikTok changes its page and API on its own schedule.
- **Private, deleted or sign-in-only clips are refused in plain words.** No cookies, no tokens, no account: only what TikTok serves openly. A refusal is a sentence in your language, never an HTTP code.

### A checkmark instead of a second download

- **The Add button turns into a green check once the track is saved**, and stops accepting clicks, so a second press cannot download the same file again.
- **It stays disabled until the file is actually on disk**, which is the same moment the row becomes playable.

### Pause from the row itself

- **The play button in the search results is a toggle now.** Press it on a playing row and it pauses; press again and it continues. The glyph follows the player rather than the row's own memory of what it started.
- **Starting another row releases the previous one**, so no row is left showing a pause button for a track the player no longer holds.

### Tracks moved out of settings

- **The collection now lives in `library.json`** beside `settings.json`, and settings keeps only preferences. A corrupt library file is not worth crashing over: you get an empty library and the broken file stays on disk for a bug report.
- **The old collection is migrated once**, on first start, and the move is recorded so it never resurrects tracks you later removed.
- **Cached file paths are checked once** after the move: a file found under the current music folder is repointed, one that is gone everywhere is marked failed instead of pretending to be playable.

### Smaller things

- **The search field has a Cancel button** while a search, a cache pass or a link download is running.
- **A slow row in the background pass is now deferred** rather than holding a slot for the full service timeout.

## Русский

1.4.0 добавляет раздел TikTok: вставили ссылку — получили звук. Ещё каждый скачанный трек получает свой файл, а маленькая кнопка прослушивания в результатах поиска становится настоящей паузой.

### TikTok

- **Третья вкладка — TikTok.** Одно поле, одна кнопка. Вставьте ссылку на ролик, нажмите «Скачать» — звуковая дорожка окажется в `Music\TikTok`.
- **Короткие ссылки тоже работают.** Ссылка вида `vm.tiktok.com/…` или `vt.tiktok.com/…` сначала раскрывается в настоящий адрес ролика, и только потом скачивается звук. Повторная вставка той же ссылки не добавит вторую копию.
- **Отмена есть, пока идёт работа.** Кнопка появляется только тогда, когда есть что останавливать, и останавливает именно это скачивание, не трогая остальной список.
- **У TikTok свой кеш.** Файлы лежат отдельно от кеша YouTube, счётчик считает только их, и «Очистить кеш TikTok» удаляет только их. Список — своя коллекция, отдельная от плейлиста «Локально»: счётчики и очистка не общие.
- **ffmpeg на этом пути не нужен.** Если TikTok отдаёт видеоконтейнер вместо отдельной звуковой дорожки, звук распаковывается тем же декодером Media Foundation, которым программа уже пользуется для кеша YouTube, и сохраняется как WAV. Ставить ничего не нужно.
- **Метаданные сначала берутся со страницы.** Сначала подписанный API, потом публичная страница, потом oembed ради названия. `yt-dlp` остаётся самым последним средством — та сборка, которой уже пользуется раздел YouTube, если она установлена, — потому что TikTok меняет страницу и API в своём темпе.
- **Закрытые, удалённые и требующие входа ролики отклоняются по-человечески.** Ни куки, ни токенов, ни аккаунта: только то, что TikTok отдаёт открыто. Отказ — это фраза на вашем языке, а не код ответа.

### Галочка вместо второго скачивания

- **Кнопка «Добавить» превращается в зелёную галочку**, как только трек сохранён, и перестаёт принимать нажатия — второй раз тот же файл не скачается.
- **Она неактивна до тех пор, пока файла нет на диске**, то есть ровно до того момента, когда строка становится воспроизводимой.

### Пауза прямо из строки

- **Кнопка прослушивания в результатах поиска стала переключателем.** Нажатие на играющую строку ставит на паузу, ещё одно — продолжает. Значок следует за плеером, а не за памятью строки о том, что она запускала.
- **Запуск другой строки отпускает предыдущую**, чтобы ни одна не осталась с кнопкой паузы для трека, которого в плеере уже нет.

### Коллекция переехала из настроек

- **Коллекция теперь живёт в `library.json`** рядом с `settings.json`, а в настройках остаются только предпочтения. Битый файл коллекции не повод падать: вы получите пустую коллекцию, а битый файл останется на диске для отчёта.
- **Старая коллекция переносится один раз**, при первом запуске, и перенос запоминается, чтобы не воскрешать треки, которые вы потом удалили.
- **Пути к скачанным файлам проверяются один раз** после переезда: файл, найденный в текущей папке с музыкой, получает новый путь, а пропавший везде помечается неудачным вместо того, чтобы притворяться воспроизводимым.

### Мелочи

- **У поля поиска появилась кнопка «Отменить»**, пока идёт поиск, проход по кешу или скачивание по ссылке.
- **Медленная строка фонового прохода теперь откладывается**, а не держит слот всё время сервисного таймаута.
